# NoirKit

键盘优先的本地开发者工具台。JSON、JWT、Hash、时间戳、正则、Base64、URL、UUID。

没有后端。输入不会离开浏览器。

## 本地打开

直接打开 `index.html`，或：

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。

## GitHub Pages

仓库 Settings → Pages → Source 选 `main` / `/ (root)`。

启用后地址通常是：

`https://anfyya.github.io/noirkit/`

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `/` | 打开工具搜索 |
| `Esc` | 关闭搜索 |
| `Enter` | 在搜索里打开第一个结果 |
